
# ShopMate AI 🛍️

**A simple small-business assistant for inventory and stock management.**

ShopMate AI is a prototype designed to help small shop owners quickly check product availability and identify items that may need restocking.

## Features

- View sample shop inventory.
- Check product stock levels.
- Ask questions about low-stock products.
- Use a simple, mobile-friendly web interface.

## Demo

ShopMate AI runs as a web application built with Streamlit.

The current prototype uses fictional sample inventory data. It is a simulated assistant and does not connect to real shop records or an Alexa+ device.

## Built With

- Python
- Streamlit
- Pandas

## Run Locally

1. Install Python.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`
